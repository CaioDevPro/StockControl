# StockControl
Sistema de Controle de Estoque - Projeto Web 2

Como fazer o primeiro acesso:

- Mova a pasta "Stock Control" para sua pasta "htdocs" do _XAMPP_;
- Ative o _Apache_ e o _MySQL_;
- Acesse o "localhost" via navegador;
- Abra o "instalador.php"

obs.: o "instalador.php" deve ser utilizado apenas uma vez.
